# AgentRelay v2 Sandbox

Disposable public sandbox for AgentRelay v2 authorization and permission tests.

This repository contains synthetic code, test data, and test-only configuration. It must never contain production data, private repository content, credentials, tokens, private keys, internal URLs, or personal information.

Automatic merging is disabled. All active probes require a separate, short-lived authorization bound to an exact test pull request and full head SHA.
